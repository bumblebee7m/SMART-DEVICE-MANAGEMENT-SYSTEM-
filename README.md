## Project Overview
A Python-based Object-Oriented Programming (OOP) project simulating a smart home central manager. Built to demonstrate classes, private state encapsulation, property parameters, validation loops, and basic module design rules.

## Core Features
- **Strict Private Fields**: Core identifiers are hidden via double-underscore formatting rules.
- **Inheritance Infrastructure**: Child components use explicit `super()` calls to build off the parent core.
- **Clean Input Safeguards**: Enforces strict boundaries (e.g., brightness limits and empty ID restrictions).
- **Interactive Control Terminal**: Features a dynamic user menu navigating functional options.
